# 묶음 판정 작업 지시 (모든 묶음 공통)

묶음 이름을 `<B>`라고 할 때 (예: b07):

1. 판정 기준을 먼저 끝까지 읽으세요: label_guide.md
2. 판정할 글: batches/<B>.jsonl (한 줄에 글 하나, 약 1,000줄). 필드: id, stock_name(게시판 종목), is_reply, execution_side(BUY/SELL/null), text, parent_text(대댓글이면 부모 글).
3. 결과 파일: labels/<B>.jsonl — 한 줄에 {"id": "...", "label": "greed|fear|neutral|irrelevant|unsure"}. 입력의 모든 id를 빠짐없이, 입력 순서대로.

진행 방법 (출력이 길어서 꼭 나눠서 하세요):
- 결과 파일이 이미 있으면 지우고 새로 시작하세요.
- 입력을 125줄씩 8번에 나눠 읽고(Read 도구의 offset/limit), 125건 판정이 끝날 때마다 Bash로 결과 파일 끝에 덧붙이세요: cat >> 결과파일 <<'EOF' ... EOF
- 다 쓰고 나서 wc -l 로 줄 수가 입력 줄 수와 같은지 확인하세요. 다르면 빠진 id를 찾아 채우세요.

규칙:
- 애매하면 반드시 unsure. 기준의 7~11번 규칙을 꼭 지키세요.
- 판정은 글을 직접 읽고 하세요. 키워드 스크립트 등으로 자동 분류하지 마세요. 임시 파일도 만들지 마세요.
- 위 두 경로 밖의 파일은 만들거나 고치지 마세요. 인터넷·외부 API 금지.
- 보고에 원문을 옮기지 마세요. 끝나면 줄 수와 라벨별 개수만 한 줄로 보고하세요.
