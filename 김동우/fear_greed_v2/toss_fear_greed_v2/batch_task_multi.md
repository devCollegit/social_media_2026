# 여러 축 판정 작업 지시 (보완안 A8)

류창민 `batch_task.md`와 같은 절차입니다. 판정 기준은 `label_guide_multi.md`입니다.

묶음 이름을 `<B>`라고 할 때 (예: m00):

1. 판정 기준을 먼저 끝까지 읽으세요: label_guide_multi.md
2. 판정할 글: multi/batches/<B>.jsonl (한 줄에 글 하나, 최대 500줄). 필드: id, stock_name, is_reply, execution_side, text, parent_text.
3. 결과 파일: multi/labels/<B>.jsonl — 한 줄에 {"id": "...", "emotion": "...", "intent": "...", "target": "..."}. 입력의 모든 id를 빠짐없이, 입력 순서대로.

진행 방법
- 결과 파일이 이미 있으면 지우고 새로 시작하세요.
- 입력을 100줄씩 나눠 읽고, 100건 판정이 끝날 때마다 결과 파일 끝에 덧붙이세요.
- 다 쓰고 나서 줄 수가 입력 줄 수와 같은지, 값이 기준표의 영어 값인지 확인하세요.

일치도 점검(두 번째 판정)일 때
- 첫 판정 결과(multi/labels/)를 보지 마세요. 결과는 multi/labels_recheck/<B>.jsonl에 쓰세요.

규칙
- 판정은 글을 직접 읽고 하세요. 키워드 스크립트 등으로 자동 분류하지 마세요.
- 기존 탐욕·공포 판정(labels/)은 보지 마세요. 두 판정을 나중에 비교합니다.
- 위 경로 밖의 파일은 만들거나 고치지 마세요. 인터넷·외부 API 금지.
- 보고에 원문을 옮기지 마세요. 줄 수와 축별 값 개수만 한 줄로 보고하세요.
