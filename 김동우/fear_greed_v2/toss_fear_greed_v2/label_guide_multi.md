# 여러 축 판정 기준 (보완안 A8)

기존 판정(탐욕·공포·중립·무관·애매, `label_guide.md`)은 그대로 둡니다. 같은 글에 아래 세 축을 **따로** 붙입니다.
기존 기준은 분노·물린 한탄을 공포로, 못 산 아쉬움을 탐욕으로 칩니다. 그래서 "탐욕/공포"에 감정과 시장 방향 의견이 섞여 있습니다(발표 13장).
세 축을 나눠 두면 "공포로 판정된 글 중 실제 겁먹은 글은 얼마인가", "탐욕 글을 쓴 사람이 실제로 사겠다고 했나"를 셀 수 있습니다.

각 축에서 **하나만** 고릅니다. 글에 여러 개가 보이면 가장 두드러진 것을 고르고, 판단할 근거가 없으면 `none`입니다.
대댓글은 부모 글(parent_text)을 읽고 판정하되, 판정 대상은 대댓글 본문입니다. "저도요"처럼 동의만 하는 글은 부모 글의 값을 따릅니다.

## 1. emotion: 글쓴이의 감정

| 값 | 뜻 | 예 (지어낸 문장) |
|---|---|---|
| `hope` | 기대·희망. 오를 거라는 바람 | "내일은 좀 오르겠지", "실적 기대된다" |
| `excitement` | 확신·흥분. 들뜬 낙관, 자랑 | "가즈아", "익절 축하합니다", "이건 무조건 간다" |
| `anxiety` | 불안·걱정. 아직 일어나지 않은 하락이 걱정됨 | "더 빠지면 어쩌지", "불안해서 잠이 안 온다" |
| `panic` | 공포·패닉. 지금 무너지고 있다는 다급함 | "다 던져", "끝났다 탈출해" |
| `anger` | 분노·불만. 회사·세력·기관·정책·남을 탓함 | "공매도 세력 때문에", "경영진 뭐 하냐" |
| `regret` | 후회·체념. 이미 손해 봤거나 못 산 것에 대한 아쉬움 | "그때 팔걸", "물렸다 존버", "못 탄 게 한" |
| `mockery` | 조롱·냉소. 비꼬기, 남의 손실을 웃음거리로 | "ㅋㅋ 또 물타기", "여기 개미들 다 망함" |
| `none` | 감정이 드러나지 않음. 정보 전달, 질문 | "실적 발표 몇 시예요?", 기사 요약 |

## 2. intent: 글쓴이가 밝힌 행동

글에 **글쓴이 자신의** 행동이 드러날 때만 고릅니다. 남에게 권하는 말("사세요")은 `none`이 아니라 그 행동으로 봅니다.
매수·매도 인증 표시(execution_side)는 참고만 하고, 본문과 다르면 본문을 따릅니다.

| 값 | 뜻 |
|---|---|
| `buy` | 샀다·사겠다·사라 (처음 사는 것) |
| `add` | 더 샀다·물타기·불타기 (이미 가진 상태에서 추가) |
| `hold` | 버틴다·안 판다·존버 |
| `sell` | 팔았다·팔겠다·손절·익절·팔아라 |
| `wait` | 지켜본다·관망·떨어지면 산다 |
| `none` | 행동이 드러나지 않음 |

## 3. target: 글이 말하는 대상

| 값 | 뜻 |
|---|---|
| `stock` | 이 종목의 주가·실적·전망 |
| `market` | 시장 전체·지수·업종·금리·환율·정책 |
| `players` | 세력·기관·외국인·공매도·작전 |
| `company` | 회사·경영진·대주주·사업 (주가가 아닌 회사 자체) |
| `investors` | 다른 투자자·이 게시판 사람들 |
| `none` | 대상이 없거나 판단 불가 |

## 출력

한 줄에 하나: `{"id": "...", "emotion": "...", "intent": "...", "target": "..."}`. 위 표의 영어 값만 씁니다.
