# 서비스 기획안: 종토방 이상일 브리핑

**"오늘 이 종목 게시판, 왜 시끄러운가?"**를 3분 안에 보여주는 브리핑 도구

| --- | --- |
| 작성 | 탁채린 |
| 작성일 | 2026-10-25 |

## 0. 한 줄 요약

주가를 맞히는 대신, **게시판 반응이 평소와 다른 날을 찾아 찬반 구성과 원문 근거를 함께 보여주는 서비스**를 만든다.

---

## 1. 왜 방향을 바꾸는가

중간보고서의 핵심 질문은 "커뮤니티 감성이 주가보다 먼저 움직이는가"였다. 실제 데이터로 확인한 결과는 다음과 같다.

| 종목 | 비교한 예측 횟수 | 감성 추가 후 예측 오차(MSE) |
| --- | --- | --- |
| 포스코퓨처엠(003670) | 31회 | 약 **1.4% 증가** |
| 에코프로머티(450080) | 32회 | 약 **7.8% 증가** |

감성 지수를 넣어도 예측이 좋아지지 않았다. 따라서 **예측이나 매매 신호를 내세우는 서비스는 우리 데이터로 정당화할 수 없다.**


### 발견: 평균 점수가 숨기는 날

**포스코퓨처엠 · 2026-08-07**

| 항목 | 관측값 |
| --- | --- |
| 게시글·댓글 수 | **733건** (직전 기준의 약 **19배**) |
| AI 판정 긍정 / 부정 | **255 / 228건** |
| 평균 감성 점수 | **+0.056** (거의 중립처럼 보임) |
| 같은 날 시장 | 수익률 약 **+5.63%**, 거래량 직전 기준의 약 **4.15배** |

평균 점수만 보면 조용한 중립의 날이다. 실제로는 **게시량이 폭증하고 찬반이 팽팽히 갈린 날**이었다. 감성 점수 하나로 요약하는 방식은 이런 날을 놓친다.

> **서비스 메시지:** 감성 점수 하나가 아니라 **찬반 구성**을 보여준다.

---

## 2. 문제 정의

| 사용자 | 겪는 문제 |
| --- | --- |
| 개인 투자자 | 관심 종목 게시판에 하루 수백 건이 올라와 다 읽을 수 없다. 무관한 글과 감정적 글이 섞여 있다. |
| 브리핑·리서치 작성자 | 어느 날짜의 뉴스·공시를 먼저 확인해야 할지 고르기 어렵다. |
| 감성 지수 이용자 | 단일 점수로는 의견이 갈린 날과 정말 조용한 날을 구분할 수 없다. |

**해결하려는 질문:** 이 종목 게시판에서 평소와 다른 날은 언제였고, 그날 사람들은 어떤 쪽으로 무슨 말을 했나?

---

## 3. 서비스 개요

### 핵심 기능 3가지

1. **이상일 자동 탐지:** 게시량이 같은 종목의 평소(직전 20거래일 중앙값)보다 크게 늘어난 날을 타임라인에 표시한다.
2. **찬반 구성 카드:** 평균 점수 대신 긍정·부정·중립의 수와 혼재도를 막대로 보여준다. AI가 판단한 글의 비율도 함께 공개한다.
3. **원문 근거 연결:** 카드의 숫자를 누르면 긍정 쪽, 부정 쪽 대표 글의 원문 인용을 볼 수 있다.

### 화면 구성 (데모 기준 3개)

```
① 종목 타임라인            ② 날짜 브리핑 카드              ③ 찬반 논거 보기
┌──────────────────┐    ┌─────────────────────────┐    ┌──────────────────┐
│ 주가 ───────       │    │ 포스코퓨처엠 · 08-07      │    │ 긍정 쪽 대표 글    │
│ 게시량 ▁▁▇▁▁▃     │ →  │ 게시량 평소의 19배         │ →  │ "…" (원문 인용)   │
│      ↑ 이상일 표시  │    │ 찬 ████▌ 반 ████ (혼재)   │    │                  │
│ [종목 선택 ▼]      │    │ 주가 +5.6% / 거래량 4.2배  │    │ 부정 쪽 대표 글    │
│ [기준 1.5x/2x/3x]  │    │ AI 판단 가능 483/733건     │    │ "…" (원문 인용)   │
└──────────────────┘    │ → 뉴스·공시 확인 권장       │    └──────────────────┘
                        └─────────────────────────┘
```

| 화면 | 사용자가 하는 일 | 보여주는 정보 |
| --- | --- | --- |
| ① 타임라인 | 종목과 이상일 기준(1.5배·2배·3배)을 고른다 | 주가, 게시량, 이상일 표시 |
| ② 브리핑 카드 | 이상일 하나를 누른다 | 게시량 배수, 찬반 구성, 혼재도, (AI 판단 범위,) 수익률 및 거래량 |
| ③ 찬반 논거 | 긍정 또는 부정 쪽을 펼친다 | 대표 글 원문 인용, 각 글의 AI 판정 |

## 4. 데이터와 구현 가능성

새로운 수집 없이 **기존 산출물만으로** 데모를 만들 수 있다.

| 기능 | 사용하는 기존 산출물 | 추가 작업 |
| --- | --- | --- |
| 이상일 탐지 | 관측 활동 배수 (148개 종목·거래일) | 없음 |
| 찬반 구성 막대·혼재도 | 긍정·부정·중립 수, 혼재도 | 없음 |
| AI 판단 범위 | 분류 가능 비율, 판단유보·혼합 수 | 없음 |
| 주가·거래량 | 수정주가 수익률, 거래량 배수 | 없음 |
| 찬반 대표 글 | LLM 판정 7,632건 + 인용 구절 | 대표 글 선정 규칙 정의 |
| 한 줄 요약 문구 (선택) | 기존 브리핑 카드 6개 | 이상일에 한해 LLM으로 미리 생성 |

### 사용할 지표

| 지표 | 계산 | 표시 방식 |
| --- | --- | --- |
| 관측 활동 배수 | 당일 글 수 ÷ 직전 최대 20거래일 중앙값 | "평소의 N배" |
| 찬반 구성 | 긍정·부정·중립 건수 | 가로 누적 막대 |
| 긍부정 혼재도 | 2 × min(긍정, 부정) ÷ (긍정 + 부정) | 1에 가까우면 "의견 갈림" 표시 |
| 분류 가능 비율 | 유효 글 ÷ 전체 글 | "AI 판단 가능 483/733건" |


### 시작 전 확인 사항

- [ ] LLM 판정 파일에 **글별 인용 구절**이 저장되어 있는가? (③번 화면에 필수)
- [ ] 관측표와 판정 파일이 같은 글 ID로 연결되는가?
- [ ] 화면에 원문을 보여줄 때 개인정보(계정명 등)가 빠져 있는가?

## 5. 범위 밖 (하지 않는 것)

| 하지 않는 것 | 이유 |
| --- | --- |
| 매수·매도 신호, 과열 경고 | 우리 데이터가 예측력을 확인하지 못했다 |
| "투자 심리 지수"라는 표현 | 2개 종목, 1개 플랫폼, 약 3.7개월 표본이라 일반화할 수 없다 |
| 실시간 수집·알림 | 수집 허용 범위가 확인되지 않았고, 데모 범위를 넘는다 |
| 판단유보 글 재분류 | 기존 AI 판정을 바꾸지 않는다는 원칙을 유지한다 |

화면에는 **"투자 판단을 위한 정보가 아니며, 원인과 효용은 검증되지 않았습니다"** 문구를 고정으로 표시한다.
