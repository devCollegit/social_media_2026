## 1. 한 줄 요약

주제 확정과 중간보고서 작성이 끝났고, 보고서에 적은 분석 절차를 **실행 가능한 코드로 전부 구현해 동작 점검까지 마쳤습니다.** 여기에 **류창민님의 공포탐욕지수 개정안(판정 기준 명확화)을 보고서에 반영**했습니다. 지금 막혀 있는 것은 코드가 아니라 **실제 데이터**입니다.

## 3. 만들어 둔 것 (`조현호/toss_sentiment/`)

```
수집 → 정제 → 감성 분류 → 시장 자료 → 거래일 집계 → 패널 병합 → 통계 검증 → 결과 요약
```

하나의 명령으로 전체를 돌리거나, 특정 단계만 다시 돌릴 수 있습니다.

```bash
cd 조현호/toss_sentiment
pip install -r requirements.txt
python run_pipeline.py plan      # 실행 계획만 확인
python run_pipeline.py run       # 전체 실행
python run_pipeline.py run --from analyze   # 통계부터 다시
```

보고서에 쓸 표·그림·요약은 `output/` 아래에 생성됩니다. 실행할 때마다 설정 지문과 단계별 지표가 기록되므로, 어떤 수치가 어떤 설정에서 나왔는지 추적됩니다.

분석 조건은 코드가 아니라 **`config/pipeline.yaml` 한 파일**에 모여 있습니다. 종목, 기간, 최소 글 수, 시차 범위, 종가 시각 등을 여기서 바꾸면 됩니다.

## 4. 중요한 전제 — 수집 코드는 일부러 안 넣었습니다

토스증권을 자동으로 긁는 코드는 저장소에 **없습니다.** 화면에 커뮤니티가 보인다는 것이 과거 전체 글을 수집해도 된다는 뜻은 아니기 때문입니다.

대신 수집은 어댑터로 분리해서, **팀이 허용된 범위에서 확보한 CSV를 읽는 경로**와 절차 점검용 합성 표본 경로만 제공합니다. 설정의 `collection_approved` 기본값은 `false`이고, 확인 없이 수집본을 읽으면 결과 요약에 "이용 조건 확인 필요" 기록이 남습니다.

**수집 시작 전에 확인할 것**
1. 이용약관·robots.txt 상 수집 허용 범위
2. 공개 API 또는 공식 제공 경로 존재 여부
3. 요청 빈도 제한과 서버 부담
4. 개인정보(작성자명·프로필) 처리 방침 — 현재 정제 단계에서 자동 제거됩니다

## 5. 동작 점검 결과 (연구 결과 아님)

실제 데이터가 없으니, **감성이 다음 거래일 수익률을 약하게 앞서는 관계를 합성 표본에 일부러 심어놓고** 코드가 그걸 찾아내는지 확인했습니다.

- 시차 상관: k=+1에서 최대 → 선행 관계를 잡아냄
- 선행 회귀: 3종목 모두 이전 감성 계수 유의
- Granger: 감성→수익률만 유의, 수익률→감성은 유의하지 않음 → **방향 구분됨**
- ADF가 비정상성을 탐지하고 Granger를 "보조 참고"로 제한하는 안전장치도 작동

**이 숫자들은 전부 합성 자료 점검 결과입니다. 보고서에 연구 결과로 쓰면 안 됩니다.** 합성 표본으로 돌리면 결과 요약 문서 맨 위에 경고가 자동으로 붙습니다.

## 6. 기획안 개정안 대비 아직 안 한 것

가로형 제안서에 적은 것 중 구현 범위에 안 들어간 항목입니다. 솔직하게 공유합니다.

- 지수 산식 개정: 분모 평활(+10)과 직전 20거래일 0~100 백분위 변환 → 미반영
- 2축 분해(방향 지수 / 과열 강도)와 5개 하위 지표, 국면 판정 → 현재는 **단일 감성 지수 S** 하나
- 패널 회귀(종목 고정효과 · 종목별 군집 표준오차) → 현재는 종목별 시계열 회귀 + Newey-West
- 판정 대상을 **다음 날 거래량**으로 두는 가설 검정 경로 → 미구현
- 장전 감성(15:30~익일 08:30) 별도 집계 → 미구현
- KRX 확장 지표(초과수익률·일중변동폭·갭·순매수비율·공매도·급등락일) → 미구현
- 추가 분석(과열 후 반전 · 맞은편 투자자 · 머신러닝 비교 · 밤사이 심리) → 미구현
- 모델 비교 → 사전 기반 기준선만 구현, 한국어 모델 경로는 코드만 있고 미실행
- 대시보드 → 미구현

실제 데이터가 확보되면 같은 컨트롤러에 단계를 추가하는 방식으로 확장할 수 있는 구조입니다.
