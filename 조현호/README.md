## 2. 프로젝트 아이디어

### 아이디어 제목

국내 거주 외국인과 내국인의 생활권 및 교류 공간 분석

### 내용

최근 국내에 거주하는 외국인이 늘고 있지만, 내국인과 외국인이 자연스럽게 어울릴 수 있는 기회나 공간은 부족한 것 같다. 특히 외국인이 주로 방문하는 식당과 내국인이 방문하는 식당이 서로 다른 것처럼 보인다.

소셜미디어 게시물이나 식당 리뷰 등의 데이터를 크롤링해 내국인과 외국인이 선호하는 식당, 지역, 문화 공간의 차이를 분석해 보고 싶다. 이를 바탕으로 두 집단이 함께 이용하고 교류할 수 있는 장소나 서비스의 방향을 찾아본다.

### 분석 방향 후보

- 내국인과 외국인이 자주 방문하는 식당 및 지역 비교
- 소셜미디어 게시물과 리뷰의 키워드 및 감성 분석
- 두 집단의 관심이 겹치는 장소나 활동 탐색
- 내국인과 외국인의 자연스러운 교류를 돕는 활용 방안 제안
