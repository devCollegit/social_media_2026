# 개인과제 → 공모전 → 책 로드맵

하나의 분석 자산(`outputs/analysis.json`)을 세 단계에 걸쳐 재사용하는 것이 핵심입니다.

```mermaid
flowchart TD
    A[1단계 개인과제<br/>research_agent] --> B[2단계 공모전<br/>contest_agent]
    B --> C[3단계 단행본<br/>book_agent]
    A -.analysis.json.-> B
    A -.analysis.json.-> C
```

## 1단계 — 개인과제 (4~6주)

| 주차 | 할 일 | 도구 |
|---|---|---|
| 1 | 연구 질문 확정, 검색어 세트 설계 | `config/research_plan.json` |
| 2 | 수집 파이프라인 안정화 (API 키 발급, 수집량 확보) | `sma collect` |
| 3 | 전처리·불용어 보강, 감성 사전 확장 | `sma tune` → `config/stopwords.txt` |
| 4 | 비교 분석 및 리포트 작성 | `sma research` |

**완료 기준**: 집단별 500건 이상 수집, 장소 겹침 지표 산출, 리포트 제출

### 품질을 올리는 포인트

- 불용어는 1차 결과의 상위 키워드를 보고 반복적으로 보강합니다. `sma tune` 이 후보를 뽑아 줍니다.
- 검색어가 곧 표본 편향입니다. 집단별 검색어 수와 성격을 대칭으로 맞추세요.
  `sma tune` 의 표본 균형 진단에서 경고가 0건이 될 때까지 조정합니다.
- 한쪽 집단에서만 흔한 단어는 불용어가 아니라 **결론**일 수 있습니다. 자동 제안을 그대로 믿지 마세요.
- 샘플 수집기는 개발·테스트용입니다. 최종 결과는 반드시 실데이터로 재생성합니다.

### 보정 루프

```
collect → tune → (stopwords.txt 수정) → analyze → 결과 확인 → 다시 tune
```

## 2단계 — 공모전 (6~10주)

| 항목 | 설명 |
|---|---|
| 보강 | 공공데이터(등록외국인 통계, 상권 정보)와 결합해 지도 시각화 (`sma geo`) |
| 차별화 | "결과"가 아니라 "재현 가능한 파이프라인"을 함께 제출 |
| 산출물 | `outputs/contest/` 의 제안서·체크리스트·일정 |

### 체크포인트

- [ ] `data/public/*.csv` 의 예시 값을 실제 공공통계로 교체 (행안부·법무부)
- [ ] `sma tune` 경고 0건 확인 (표본 편향 해소)
- [ ] 데이터 출처와 라이선스 명시
- [ ] 개인정보 비식별 처리 근거 문서화
- [ ] 심사 배점표 기준 자가점검 (`체크리스트.md`)
- [ ] 발표 리허설 2회 이상

### 지원할 만한 공모전 유형

- 공공데이터 활용 아이디어·분석 공모전
- 지자체 다문화/외국인 정책 제안 공모전
- 대학·학회 주최 데이터 분석 경진대회

## 3단계 — 단행본 (6~12개월)

| 단계 | 내용 |
|---|---|
| 기획 | `outputs/book/기획안.md` 기반으로 독자·포지셔닝 확정 |
| 자료 보강 | 분석 대상 도시를 2~3곳으로 확장, 인터뷰 추가 |
| 집필 | 장별 초고 스켈레톤에 서사와 인터뷰를 채움 |
| 검증 | 각 장의 '데이터 노트'를 최신 `analysis.json` 으로 재생성 |

### 책으로 확장할 때의 원칙

1. **수치는 자동, 서사는 수작업.** 데이터 노트는 에이전트가 갱신하고 본문은 직접 씁니다.
2. **재현 가능성이 차별점.** 독자가 자기 도시로 설정만 바꿔 돌릴 수 있어야 합니다.
3. **집단 비교는 기술(description)에 머문다.** 우열이나 원인 단정은 피합니다.

## 확장 아이디어

- 시계열 분석: 분기별로 수집해 교류 공간의 증감 추적
- 문서 단위 지오코딩: 시군구 대표 좌표 대신 장소명을 좌표로 변환해 히트맵 작성
- 토픽 모델링: LDA/BERTopic 으로 변별 키워드를 주제 단위로 묶기
- 인터뷰 결합: 공유 장소 운영자 인터뷰로 정성 근거 확보
- 상권 데이터 결합: 업종·임대료와 교류 지수의 관계 분석

## 지표 해석 가이드

| 지표 | 높을 때 | 낮을 때 |
|---|---|---|
| 장소 자카드 | 생활권 공유 | 생활권 분리 ('분리된 도시' 논지) |
| 교류 지수 | 두 집단이 고르게 언급하는 지역 | 한 집단이 독점하는 지역 |
| 거주–활동 상관 | 소셜 데이터가 실거주 분포를 잘 반영 | '사는 곳'과 '노는 곳'이 다름 |
| 거주 대비 언급 격차(+) | 활동·소비 중심지 | 거주 중심, 소셜 노출 적음 |
