# 공공데이터

소셜 분석 결과와 결합하는 지역 단위 통계입니다.

## foreign_residents.csv

| 컬럼 | 설명 |
|---|---|
| `region` | 시도 + 시군구 (예: `서울 용산구`). 수집 문서의 `region` 앞 2개 토큰과 매칭됩니다. |
| `population` | 해당 지역 총인구 |
| `foreign_residents` | 등록외국인 수 |
| `source` | 출처 표기 |

> ⚠️ 현재 들어 있는 값은 **구조 확인용 예시 데이터**입니다.
> 실제 분석·공모전 제출 전에 반드시 아래 출처의 실제 통계로 교체하세요.
>
> - 행정안전부 「주민등록 인구통계」 — 지역별 총인구
> - 법무부 「출입국·외국인정책 통계월보」 / 행정안전부 「지방자치단체 외국인주민 현황」 — 등록외국인 수
> - 공공데이터포털(data.go.kr)에서 CSV 내려받아 위 컬럼명으로 맞추면 그대로 사용됩니다.

## region_coords.csv

| 컬럼 | 설명 |
|---|---|
| `region` | `foreign_residents.csv` 와 동일한 표기 |
| `lat`, `lon` | 지도 표시용 대표 좌표 |

좌표는 시군구 대략적 중심점입니다. 더 정밀한 분석이 필요하면 장소명을 지오코딩해
문서 단위 좌표를 사용하세요.

## 지역 추가하기

두 CSV에 같은 `region` 값으로 행을 추가하기만 하면 됩니다. 코드 수정은 필요 없습니다.
통계에 없는 지역은 지도와 상관분석에서 자동으로 제외되며, 리포트에 누락 지역으로 표시됩니다.
