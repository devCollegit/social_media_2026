## 담당 작업: 데이터 수집 파이프라인

토스증권 커뮤니티 글·댓글과 KRX 시세를 조현호 파이프라인 입력 형식으로 모으는 작업. 자세한 내용은 [data_collection/README.md](data_collection/README.md).

- [수집 가능성 점검표](data_collection/docs/수집가능성_점검표.md): 약관상 명시적 허용이 없어 토스증권 네트워크 수집은 보류, 이용 문의 진행 중
- [개발 기록](data_collection/docs/개발기록.md): 결정 사항, 발견한 문제, 검증 결과
- [작업 이관 메모](data_collection/docs/작업이관.md): 다른 환경에서 이어서 작업하는 방법, 현재 상태, 다음 할 일
- 완료: 시세·지수·종목 마스터 수집(`market/`), 커뮤니티 파서·저장·증분·재시도(`collector/`, 합성 데이터로 검증)
