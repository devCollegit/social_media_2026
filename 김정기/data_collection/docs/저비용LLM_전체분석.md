# 전체 자료의 저비용 LLM 분석 결과

2026-10-21. gpt-6-luna medium 에이전트 3개가 고정 지시문으로 전체 정제 글·댓글 **7,632건**을 판정했다.
대상은 포스코퓨처엠(003670)·에코프로머티(450080), 2026-07-01~10-20의 종목별 74거래일이다.
추가 사람 검수는 보류했다. 기존 사람 답안과 사전 예측을 분류 에이전트에 제공하지 않았다.
원문·예측·인용 근거는 Git 제외 state/data에 보존했고, 기존 사전 결과는 교체하지 않았다.

## 어떤 글을 분류했나?

| 감정 | 건수 |
| --- | --- |
| 긍정 | 1,552 |
| 중립 | 820 |
| 부정 | 2,477 |
| 혼합 | 432 |
| 판단유보 | 2,351 |

관련성은 관련 5,666건, 무관 1,072건, 불명 894건이었다.
긍정·중립·부정으로 답한 관련 글은 **4,849건(63.5%)**이다.
판단유보와 혼합은 지수 분모에서 제외하고 건수를 별도로 기록했다.
이 판정은 LLM의 추정이며 투자자의 실제 의도에 대한 확정 정답이 아니다.

## 일별 지수와 자료 범위

| 종목 | 전체 거래일 | 유효 지수 날짜 | 배정된 글 | 유효 분류 글 |
| --- | --- | --- | --- | --- |
| 003670 | 74 | 73 | 4,373 | 3,092 |
| 450080 | 74 | 74 | 3,229 | 1,733 |

15:30 이후 글은 다음 거래일로 배정한다. 마지막 시세 종가 뒤의 30건은 배정할 거래일이 없어 제외됐다.
지수는 (긍정 - 부정) / 판단 가능한 관련 글 수이며 중립을 분모에 포함한다.
유효 글이 5건 미만인 날짜는 0이 아니라 결측이다.
무관·유보 제외는 선택 편향을 만들 수 있으므로 이 지수는 게시판 전체 글의 감정과 다른 측정이다.

## 기존 300건 사람 판정과의 기술적 비교

LLM이 3방향으로 답한 **동일 194건**에서 사람과 일치한 비율:

| 방식 | 사람과 일치 | Macro-F1 |
| --- | --- | --- |
| LLM | 56.2% | 0.5097 |
| 기존 사전 | 48.5% | 0.3222 |
| 항상 중립 | 52.6% | 0.2297 |

사람 판정도 불확실한 단독 검수자 기준이다. LLM이 고른 부분집합의 일치율을 전체 정확도로 해석하지 않는다.
첫 300건은 이미 앞선 진단에 사용됐으므로 최종 독립 평가 표본도 아니다.

## 판정 일관성도 완벽하지 않다

파일럿과 전체 실행에서 본문·부모 맥락이 같았던 300건 중 감정 판정은 198건(66.0%),
관련성은 234건(78.0%), 둘 모두는 176건(58.7%) 일치했다.
작업 범위·묶음 순서·에이전트 실행 맥락이 달라 모델 난수만의 영향을 측정한 통제 실험은 아니다.
그러나 현재 에이전트 작업 방식이 완전히 안정적이라고 주장할 수는 없다.
사람의 반복 판정을 측정하지 않았으므로 사람보다 더 일관적이라고 비교할 근거도 없다.

전체 자료 안에서 같은 종목·본문·부모 맥락이 반복된 그룹은 50개(113행)였다.
그중 43그룹은 관련성과 감정이 모두 동일했다.
반복된 글 쌍의 결합 판정 일치율은 71/80(88.8%)였다.
이는 중복 관측 진단으로 객관적 정확도나 통제된 재실행 안정성은 아니다.

## 주가와의 관계: 사후 탐색

고정한 두 방식·두 종목·세 최소 글 수·11개 시차의 132개 탐색 검정을 하나의 BH 보정군으로 계산했다.
보정 후 q<0.05인 항목은 10개다.
Pearson p값은 시간 의존성을 보정하지 않았으므로 이 숫자로 확정적인 예측력이나 인과관계를 주장하지 않는다.

기존 expanding-window 방식으로 각 방식의 동일 학습·평가 자료에서 감성 추가 모델과 통제변수 모델을 비교했다.
아래 비율은 **감성 추가 MSE / 통제변수만 사용한 MSE**다. 1보다 작으면 해당 표본에서 오차가 작았다.

| 방식 | 종목 | 예측 건수 | MSE 비율 |
| --- | --- | --- | --- |
| llm | 003670 | 31 | 1.0144 |
| lexicon | 003670 | 32 | 1.0369 |
| llm | 450080 | 32 | 1.0781 |
| lexicon | 450080 | 32 | 1.0179 |

방식마다 결측이 달라 학습·평가 날짜도 다를 수 있으므로 표의 LLM과 사전 MSE를 직접 순위 비교하지 않는다.
같은 2종목·기간을 재분석한 사후 진단이며 미래 기간 홀드아웃 성능은 아니다.

## 집계 오류를 잡은 과정

실제 자료 대조에서 naive 시각을 UTC로 해석해 9시간 미는 구현 오류를 발견했다.
clean CSV의 naive 시각은 한국 현지 시각으로 유지하고, offset-aware 시각만 한국 시각으로 변환하도록 수정했다.
naive·UTC 표기·+09:00 표기가 같은 시각이면 같은 거래일로 가는 회귀 테스트를 추가했다.
수정 후 148개 종목·거래일 모두 기존 패널의 전체 글 수와 정확히 일치했다.
첫 잘못된 daily 출력은 SUPERSEDED 표시를 붙여 보존하고 연구에는 daily_corrected만 사용했다.
감정 판정·사람 라벨·원문은 수정하지 않았다.

## 검증과 한계

- 전체 ID·행 수·batch SHA·지시문 SHA·판정 값·원문 인용의 정확한 포함 여부를 확인했다.
- 인용이 존재한다는 검사는 해석이 옳다는 검증이 아니다.
- 모델 버전은 세션 명칭이며 API snapshot·temperature·seed·실제 비용은 미확인이다.
- 행별 사람 답안은 숨겼지만 AGENTS의 과거 집계 수치는 읽을 수 있어 완전한 정보 차단 실험은 아니다.
- 개별 글은 묶음 안에서 판정됐다. 실행 맥락·묶음 효과를 완전히 통제한 독립 추론 실험은 아니다.
- 부모 맥락이 없는 댓글, 풍자, 혼합 감정과 관련성 판단의 오류가 남을 수 있다.
- 지수와 가격을 나란히 그린 그림은 관계를 확인하기 위한 탐색 그림이며 예측력의 증거가 아니다.

실제 결과 위치: state/llm_full_20261021/assembled, evaluation, daily_corrected, study, figures.
figures/atmosphere.png와 atmosphere.svg에는 지수·시세·유효 분류 비율을 함께 그렸다.
원문·예측과 실행 산출물은 Git에 포함하지 않는다. 아래 집계 SVG 그림만 문서에 제공한다.

## 다음에 할 일

전체 판정과 집계는 완료했으므로 추가 라벨링을 바로 요구하지 않는다.
자료 범위·유보 비율·모델 일관성의 한계를 연구 보고에 반영하고,
