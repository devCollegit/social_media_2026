### 2. 결정 사항

| 결정 | 이유 |
| --- | --- |
| 네트워크 호출부(`TossFetcher`)는 구현하지 않고, 파서·저장·증분·재시도만 먼저 구현 | 허락 전에는 실제 요청을 보내지 않는다. 허락이 나면 호출부만 채우면 된다 |
| `collection_approved: false` 이면 `--source toss` 실행 자체를 막음 | 조현호 파이프라인의 같은 이름 플래그와 맞춤. 확인 절차를 건너뛰는 실행 방지 |
| 응답에서 필요한 필드만 화이트리스트로 꺼냄 | 개인정보를 "지우는" 방식은 새 필드가 생기면 새어 나간다. 꺼낼 것만 정하면 그럴 일이 없다 |
| `badge` 는 체결 인증(`execution.orderSide`)만 사용, 작성자 뱃지(`author.badge`, 예: "1억대 자산가")는 버림 | 기획안의 "매수·매도 인증"은 체결 인증이다. 작성자 뱃지는 자산 규모를 드러내는 개인 정보 성격 |
| `is_holder`(주주 표시) 추가 컬럼 | 응답에 글 단위로 있고, 인증 비율 지표의 보조로 쓸 수 있음. 필요 없으면 무시하면 됨 |
| 체결 수량·금액은 저장하지 않음 | 방향(BUY/SELL)만 있으면 기획안 인증 비율을 계산할 수 있다 |
| `created_at` 을 `...ffffff+09:00` 고정 형식으로 저장 | 3.1 참고 |
| 같은 글을 다시 보면 upsert(공감 수 등 최신 값으로 교체) | 공감 수는 시간이 지나며 늘어난다. 행은 늘리지 않는다 |
| 증분 수집은 "마지막 글 시각 − 48시간"까지 다시 봄 | 최근 글의 공감 수·댓글 수가 계속 바뀌므로 겹쳐 본다. 댓글 수가 늘어난 글만 댓글을 다시 받는다 |
| 요청 간격 하한 1초를 코드로 강제(기본 2초), 병렬 요청 미지원 | 서버 부담 금지 규칙 |
| 수정주가 시세는 매 실행 전체 기간을 다시 받아 덮어씀 | 액면분할 등이 있으면 과거 수정주가가 소급해 바뀐다. 이어 붙이면 불연속이 생긴다 |
| pykrx 기본 + FinanceDataReader 보조 | 3.2 참고 |

### 3. 발견한 문제

#### 3.1 작성 시각 형식이 섞여 온다

관찰한 응답에서 `createdAt` 이 `2026-10-19T20:29:42.326512699+09:00`(나노초)와
`2026-10-19T20:28:25+09:00`(초 단위)로 섞여 왔다. 한 컬럼에 형식이 섞이면 pandas 2.x 의 `to_datetime` 이
첫 값으로 형식을 추론하고 나머지를 해석하지 못할 수 있다. 조현호 `s01_collect` 는 해석 실패를
`errors="coerce"` 로 버리므로 **오류 없이 글이 조용히 빠진다.**

수집 단계에서 모든 시각을 마이크로초 6자리 + `+09:00` 고정 형식으로 바꿔 저장하도록 했다.
테스트(`test_output_passes_pipeline_collect_normalize`)가 조현호 `_normalize` 를 통과해 결측 0건인 것을 확인한다.

#### 3.2 pykrx 가 KRX 로그인 없이는 대부분 비어 있다

pykrx 1.2.9 에서 KRX 정보데이터시스템 엔드포인트가 로그인을 요구한다. 로그인 없이 확인한 결과:

| 함수 | 로그인 없이 |
| --- | --- |
| `get_market_ohlcv(..., adjusted=True)` 수정주가 | 동작 (네이버 경유) |
| `get_market_cap` 거래대금·시총·상장주식수 | 빈 결과 |
| `get_index_ohlcv` 지수 | 실패 |
| `get_market_ticker_list`, `get_market_sector_classifications` | 빈 결과 / 실패 |

그래서 로그인 환경변수(`KRX_ID`, `KRX_PW`)가 있으면 pykrx 로 전부 받고, 없으면 지수·종목 마스터를
FinanceDataReader(`KS11`, `KQ11`, `StockListing('KRX')`, `StockListing('KRX-DESC')`)로 받도록 나눴다.
로그인이 없을 때 `value`, `market_cap`, `shares` 는 비운다. 기획안의 회전율(거래량 ÷ 상장주식수)을 계산하려면
**KRX 로그인이 필요하다.** 계정은 팀원이 직접 만들어 환경변수로 넣는다.

#### 3.3 `KOSDAQ GLOBAL` 구분

KRX 종목 목록은 코스닥 우량주 50종목의 시장을 `KOSDAQ GLOBAL` 로 표기한다. 처음에는 이 종목들이
후보에서 빠졌다(에코프로비엠 등). 마스터 단계에서 `KOSDAQ` 으로 합쳤다.

#### 3.4 종목 식별자

토스 커뮤니티는 종목코드가 아니라 ISIN(`KR7005930003`)으로 게시판을 구분한다.
종목 마스터에 `isin` 컬럼을 넣어 두었다. 2,866종목 전부 ISIN이 있다.

### 4. 조현호 파이프라인 호환성

조현호 폴더 코드는 수정하지 않았다. 읽기 전용으로 불러와 확인만 했다.

| 확인 | 결과 |
| --- | --- |
| 커뮤니티 CSV → `s01_collect._normalize` | 통과. 6건 전부 시각 해석 성공, 게시글 4·댓글 2 구분, 추가 컬럼 보존 (pytest) |

#### 4.1 제안 패치 (조현호 파이프라인, 적용하지 않음)
