## 7. 역할 통합 후 진행 현황 (2026-10-21)

`label`에는 대상 종목에 대한 긍정·중립·부정 중 하나를 적고, 맥락 부족·풍자·혼합 감정은

### 7.5 팀 검수 담당자용 명세와 실행 안내

최신 지시로 사람 검수는 김정기 역할에서 제외한다. 담당자를 임의로 지정하지 않고 팀의 지정을 기다리는 업무로 명시했다.
상위 README는 프로젝트 흐름·현재 결과·데이터 별도 전달을, docs/검수명세.md는 라벨 기준·보류 처리·제출물·완료 조건을,
review_tool/README.md는 초기 실행·화면 설명·저장/재개·내보내기·오류 해결을 설명한다.
GitHub Mermaid 흐름도와 순서도를 포함했으며 비개발자 팀원이 코드 없이 업무를 이해할 수 있게 구성했다.
실제 검수 데이터나 계정은 Git에 추가하지 않고 팀원에게 자동 전송하지 않았다.
