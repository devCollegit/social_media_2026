```bash
git clone https://github.com/devCollegit/social_media_2026.git
cd social_media_2026

cd 김정기/data_collection
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q          # 22 passed 이면 정상 (네트워크 없음)
```

## 2. git 에 없는 것 (새 노트북에서 다시 만든다)

| 항목 | 다시 만드는 방법 |
| --- | --- |
| `.venv/` | 위 1절 |
| `data/raw/market/*.csv` (3종목 시세·지수) | `.venv/bin/python -m market.cli prices` (약 5초) |
| `data/raw/meta/stock_master.csv`, `candidates.csv` | `.venv/bin/python -m market.cli candidates --top 300` |
| `logs/`, `state/` | 실행하면 생긴다. 지금까지 실제 커뮤니티 수집은 없었으므로 옮길 상태 없음 |
| KRX 로그인 | 새 노트북 셸에서 직접 `export KRX_ID=... KRX_PW=...` (파일에 적거나 커밋하지 않기) |

## 3. 현재 상태

| 단계 | 상태 |
| --- | --- |
| 1단계 수집 가능성 점검 | 완료. 약관상 명시적 허용 없음 → 토스 네트워크 수집 보류. **팀이 토스증권에 이용 문의 메일 발송 예정** |
| 2단계 수집기 | 파서·저장·증분·재시도·CLI 완료(합성 fixture 로 검증). `TossFetcher` 는 허락 전까지 미구현, `collection_approved: false` 로 차단 |
| 3단계 시세 | pykrx 수정주가 + FDR 지수·마스터 완료. KRX 로그인 없이 `value`, `market_cap`, `shares` 비어 있음 |
| 3단계 종목 선정 | 후보 300종목만 산출. 일평균 글 수 측정은 커뮤니티 수집 허락 후 |
| 4단계 연동 검증 | 모듈 단위로만 확인(s01·s04). `run_pipeline.py run --until merge` 전체 실행은 아직 |

## 4. 다음에 할 일 (우선순위 순)

1. PR 확인·리뷰 반영 (아래 5절)
2. KRX 계정 만들어 로그인 환경에서 `market.cli prices` 재실행 → `value`, `market_cap`, `shares`, `krx_sector` 채워지는지 확인
3. 4단계 일부 선행: 시세는 실제 데이터, 커뮤니티는 fixture CSV 로 조현호 파이프라인 `run --until merge` 실행해 형식 점검
   (조현호 폴더 코드·설정은 수정 금지. 설정은 복사본을 `-c` 로 넘긴다)
4. 토스증권 회신 후: 허락 범위를 점검표에 기록 → `TossFetcher` 구현 → 후보 300종목 예비 수집 → 일평균 20건 이상 종목 확정
