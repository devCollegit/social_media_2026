## 3. 컬럼 설명

| 컬럼 | 의미 |
| --- | --- |
| record_id | 이번 공유본 안에서 사용하는 임의 ID |
| stock_id | 종목코드. 문자열로 읽어 앞자리 0 유지 |
| created_date | 원래 작성 날짜, 한국 시각 기준 |
| trading_date | 분석에 배정한 거래일. 마지막 종가 뒤 30건은 빈 값 |
| parent_record_id | 부모 글이 자료 안에 있으면 그 공유 ID. 없거나 독립 글이면 빈 값 |
| text_norm | 정제 본문. 공개 보류면 빈 값 |
| text_status | available: 본문 포함 / withheld_privacy_screen: 공개 보류 |
| text_excel_escaped | 스프레드시트 수식 실행 방지를 위해 앞에 작은따옴표를 붙였는지 |
| parent_text | 댓글 해석에 쓰는 부모 본문. 없거나 공개 보류면 빈 값 |
| parent_text_status | available / withheld_privacy_screen / top_level(독립 글) / parent_missing(원래 맥락 없음) |
| parent_excel_escaped | 부모 본문의 스프레드시트 수식 방지 여부 |
| relevance | related(대상 종목 관련) / unrelated(무관) / unclear(불명) |
| sentiment | 긍정 / 중립 / 부정 / 혼합 / 판단유보 |
| model_context_used | 원래 AI 실행에서 부모 맥락 사용을 기록한 값. 현재 공개본의 부모 제공 여부와는 다름 |
| model_name | 실제 분류에 사용한 세션 모델 명칭 |

거래일은 이전 거래일 종가 직후부터 당일 15:30까지의 구간입니다.
휴일·장후 글은 다음 거래일로 넘기며, 다음 시세 날짜가 없는 30건도 공유 파일에는 남겼습니다.
원래 post_id로 기존 사람 검수 파일이나 다른 원자료와 병합할 수는 없습니다.

## 4. Python으로 읽기

```python
import pandas as pd

# 김정기/data_collection 폴더에서 실행
frame = pd.read_csv(
    'shared/analysis_7632/records.csv',
    dtype=str,
    keep_default_na=False,
)
print(len(frame))  # 7632
print(frame.groupby('stock_id')['sentiment'].value_counts())

# 본문이 제공된 행만 텍스트 분석에 사용
texts = frame[frame['text_status'] == 'available'].copy()
print(len(texts))  # 6849

# CSV 수식 방지용 작은따옴표가 있는 경우 명시적으로 제거
escaped = texts['text_excel_escaped'].eq('True')
texts.loc[escaped, 'text_norm'] = texts.loc[escaped, 'text_norm'].str.slice(1)
```

Excel에서는 CSV를 더블클릭하기보다 **데이터 → 텍스트/CSV 가져오기**에서
stock_id를 텍스트로 지정해야 앞자리 0을 유지하기 쉽습니다.
