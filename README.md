# 소셜미디어 분석 프로젝트

6조 팀원들의 관심 분야와 프로젝트 아이디어를 취합하기 위한 저장소입니다.

## 팀원

- 이우창
- 조현호
- 김동우
- 류창민
- 송이현
- 김정기
- 탁채린

## 작성 방법

1. 본인 이름의 폴더로 이동합니다.
2. 폴더 안의 `README.md`를 열어 아래 두 항목을 작성합니다.
3. 작성한 내용을 커밋하고 저장소에 반영합니다.

GitHub 사용이 어려운 분은 카카오톡에 내용을 남겨 주세요. 확인 후 대신 반영하겠습니다.

## 작성 항목

### 1. 희망 분야 및 강점

아래 분야 중 관심 있거나 자신 있는 분야를 자유롭게 작성해 주세요. 여러 분야를 선택해도 됩니다.

- 데이터베이스 구축 및 크롤링
- 데이터 분석 및 개발
- 발표 자료 제작
- 발표
- 기타

### 2. 프로젝트 아이디어

소셜미디어 분석과 관련해 진행해 보고 싶은 아이디어를 1개 작성해 주세요. 분석 대상, 활용할 데이터, 기대 결과 등을 함께 적으면 아이디어를 구체화하는 데 도움이 됩니다.

## 진행

전체 의견을 취합한 뒤 주제를 선정하고 역할과 일정을 함께 조율할 예정입니다. 잘 부탁드립니다.

## 분석 파이프라인 프로토타입

조현호 님 아이디어(내국인·외국인 생활권 비교)를 기준으로 실행 가능한 수집·분석 파이프라인을 [`project/`](project/) 에 구현해 두었습니다. 주제가 바뀌어도 `project/config/research_plan.json` 의 검색어와 집단 정의만 수정하면 그대로 재사용할 수 있습니다.

```bash
cd project
PYTHONPATH=src python3 -m sma all
```

자세한 사용법은 [project/README.md](project/README.md), 공모전·출판까지의 계획은 [project/docs/로드맵.md](project/docs/로드맵.md) 를 참고해 주세요.
